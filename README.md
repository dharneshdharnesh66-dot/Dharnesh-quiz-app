#Quiz App

A small computer-basics quiz website using HTML, CSS and JavaScript.

## What it does
- Shows three multiple-choice questions, one at a time.
- Highlights the correct answer and a wrong selection.
- Shows the final score and lets you play again.

## Run it
Download index.html and open it in a web browser. No installation is needed.
